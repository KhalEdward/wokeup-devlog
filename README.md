# WOKEUP Devlog

> 把每一次训练，变成看得见的成长。

WOKEUP 是一款正在开发中的健身 RPG 应用。我们希望把真实训练中的重量、次数、组数和持续时间转化为清晰的等级与肌群段位，让用户不只看到一条训练记录，也能感受到自己正在升级。

项目将优先推出 Android 版本，后续再开发 iOS 版本。目前应用仍处于本地测试阶段，暂未开放账号登录和云同步。

## 核心功能

- Routine 训练计划与自由训练
- 记录动作、重量、次数、组数和组间笔记
- 训练计时与后台训练通知
- 胸部、背部、腿部、肩部、手臂和核心独立段位
- 初学者、白银、黄金、白金、钻石、挑战者、奥林匹斯七个大段位
- 每个大段位包含 III、II、I 三个小段位
- 人体肌群进度图
- 成长能量与等级经验机制
- SQLite 本机训练数据保存
- 周联赛与排行榜积分原型

## 设计原则

### 真实力量与活跃等级分离

力量段位只由真实训练表现决定，等级经验用于奖励持续训练。仅靠重复记录经验，不能提高力量段位。

### 付费不影响竞技公平

未来 WOKEUP 计划通过广告和 Plus 会员盈利，但广告和会员不会直接提高力量段位，也不会出售成长能量来制造付费刷经验的捷径。

### 用户可以正常训练

即使成长能量耗尽，训练记录仍会保存，连续训练和力量段位仍会正常计算。能量只限制等级经验，不限制用户健身。

## 开发计划

- 完善训练记录和 Routine 编辑体验
- 继续校准各动作的力量评分标准
- 优化肌群人体模型与段位展示
- 设计账号登录与云端可信数据同步
- 完善真实用户周联赛分组、晋级与降级
- 开展小规模 Android 真机测试
- 准备隐私政策、用户协议与应用商店资料
- 后续加入账号登录、云同步和 iOS 版本
